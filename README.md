# KID assistant

Work in progress. An assistant that answers questions about the Key Information Documents (KIDs) of investment funds, using a small language model running locally.

## Status

Step 1 of 4: structured extraction of the risk indicator and costs from a KID.

## Data

KID PDFs are not committed to this repository. A manifest and a download script will be added.
